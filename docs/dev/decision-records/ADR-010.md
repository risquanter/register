# ADR-010: Error Handling Strategy

**Status:** Accepted  
**Date:** 2026-01-17  
**Tags:** errors, validation, zio, functional-programming

**Scope:** how failures are represented and flow as **typed values** — from
domain validation to the HTTP edge. Its counterpart **ADR-033** governs the
places where an exception physically exists (a throwing API, an asserted
invariant) and how each is caught and converted into these values.

---

## Context

- Errors are **values**, not exceptions—use typed error channels
- Validation errors **accumulate**—don't fail fast on first error
- HTTP boundary maps **typed errors to status codes**—no string matching
- Domain errors are **machine-readable**—typed codes for client handling
- Service layer **logs before boundary**—pure encoding at HTTP edge

---

## Decision

### 1. One Failure Shape

Every failure the server produces is a value of `Failure`. A variant names the
kind of answer, and every variant wraps the same `Core`:

```scala
final case class Core[Z, P](
  zone:        Z,                                 // the side of a trust boundary the failing value came from
  errors:      NonEmptyList[(ErrorLocation, P)],  // where and what, for every refusal
  diagnostics: List[Diagnostic]                   // log-only; never reaches the wire
)

enum Failure:
  case Rejected    (core: Core[TrustZone,                  FieldProblem])
  case Unanswered  (core: Core[PeerZone,                   OutageMode])
  case NotFound    (core: Core[TrustZone,                  NotFoundKind])
  case Conflict    (core: Core[TrustZone,                  ConflictKind])
  case AccessDenied(core: Core[TrustZone,                  DenialKind])
  case Expired     (core: Core[TrustZone.Client.type,      ExpiryDetail])
  case NotSupported(core: Core[TrustZone.Environment.type, Capability])

enum TrustZone:
  case Client, Environment, MeshHeader, Service
  case Peer(peer: PeerZone)

enum PeerZone:
  case Store, Database, Authorization
```

The zone is a field, so what depends on it is one total function rather than a
choice made per error type. `origin` is `Caller` for the `Client` zone and
`Service` for every other zone, and decides the log level (ADR-002 §5).
`toWire` is total over `(variant, zone)` (ADR-035 §1). A variant's type
parameter narrows the zones it admits: an expiry names only the caller, a
missing capability only the deployment's environment.

A refusal is located once and kept as a list, so independent refusals from one
input arrive together. `Failure.rejected` is the one way a `Validation` of
`ValidationError`s becomes a failure.

A refused compare-and-set or a refused merge is not a failure. `IrminClient`
returns it as `IrminWriteOutcome` or `IrminMergeOutcome`, and the caller, which
holds the expected head, builds the `Failure` its own request answers with.

The `AppError` sealed trait still holds the leaves that have not moved onto this
shape. A signature that can produce both reads `IO[AppError | Failure, A]`, and
narrows to `IO[Failure, A]` once its last `AppError` producer is gone.

### 2. Typed Validation Errors

A validation error is a location and a problem, and both are closed sets:

```scala
case class ValidationError(
  location: ErrorLocation,  // Where: ErrorLocation.requestField(FieldName.RootId)
  problem: FieldProblem     // What: FieldProblem.RootIdNotFound(rootId)
)
```

The error carries no sentence. `FieldProblem.code` derives the machine-readable
code from the problem, so the two cannot disagree. A reader that needs text
renders it from the problem: the browser renders its own sentence, and
`ValidationError.describe` gives the diagnostic text for a log line.

```scala
enum ValidationErrorCode:
  case REQUIRED_FIELD, INVALID_FORMAT, INVALID_RANGE, INVALID_LENGTH
  case INVALID_PATTERN, CONSTRAINT_VIOLATION, INVALID_COMBINATION
```

### 3. ZIO Prelude Validation for Accumulation

Smart constructors return `Validation[ValidationError, A]` to collect all errors:

```scala
def create(...): Validation[ValidationError, RiskLeaf] = {
  val idV = refineId(id, ErrorLocation.requestField(FieldName.Id))
  val nameV = refineName(name, ErrorLocation.requestField(FieldName.Name))
  val probV = refineProbability(prob, ErrorLocation.requestField(FieldName.Probability))
  
  Validation.validateWith(idV, nameV, probV) { (id, name, prob) =>
    RiskLeaf(id, name, prob, ...)
  }
}
```

### 4. Hybrid Error Channel Strategy

**Domain layer:** `Validation[ValidationError, A]` (typed, accumulates)  
**Service layer:** `Task[A]` with sealed hierarchy (simpler composition)  
**HTTP boundary:** Pattern match on `AppError` (recovers type safety)

```scala
trait RiskTreeService {
  def create(req: RiskTreeDefinitionRequest): Task[RiskTree]
  def getLECCurve(id: TreeId, nodeId: NodeId, ...): Task[LECCurveResponse]
}
```

**Tradeoff:** We accept weaker signature-level documentation in exchange for simpler ZIO composition. Type safety recovered at HTTP boundary via sealed trait pattern matching.

### 5. Pure HTTP Error Mapping

`Failure.toWire` projects a failure onto `WireError` by matching on the variant
and then the zone, with no string parsing. A value from the `Client` zone
answers its own wire case, and content a peer returned answers the opaque fault:

```scala
case Conflict(c) => c.zone match
  case TrustZone.Client => WireError.Conflict(problemOf(c), t)               // 409
  case TrustZone.Environment | TrustZone.MeshHeader | TrustZone.Peer(_) | TrustZone.Service =>
    WireError.InternalFault(t)                                               // 500
case Unanswered(_) => WireError.DependencyUnavailable(t)                     // 503
```

The projection is one-way: nothing reconstructs a `Failure` from the wire. The
match has no wildcard, so a new variant or zone that no arm handles is a compile
error rather than a leak; that guarantee is
[ADR-035](./ADR-035-error-leakage-prevention.md).

## Code Smells

### ❌ Throwing Exceptions

```scala
// BAD: Throw exception
def validate(value: Int): Int =
  if value < 0 then throw new IllegalArgumentException("must be positive")
  else value

// GOOD: Return error in type
def validate(value: Int): Validation[ValidationError, PositiveInt] =
  refinePositiveInt(value, ErrorLocation.Whole)
```

A third-party API that throws *at* you is not this smell — converting it is
ADR-033's boundary.

### ❌ Fail-Fast Validation

```scala
// BAD: Stop at first error
for {
  id   <- refineId(rawId).toZIO
  name <- refineName(rawName).toZIO  // Never runs if id fails
} yield (id, name)

// GOOD: Accumulate all errors
Validation.validateWith(refineId(rawId), refineName(rawName)) { (id, name) =>
  (id, name)  // Reports both errors if both fail
}
```

### ❌ String Matching on Errors

```scala
// BAD: Parse error messages
def fromAppError(e: AppError, trace: TraceId, scope: TreeScope) = e.logMessage match {
  case msg if msg.contains("validation") => WireError.ValidationRejected(...)
}

// GOOD: Pattern match on types
def fromAppError(e: AppError, trace: TraceId, scope: TreeScope) = e match {
  case ValidationFailed(errors) => rejected(RejectionDetail.Fields(errors), errors)
}
```

The parameter is an `AppError` and not a `Throwable`: an `AppError` is plain data
describing an expected outcome, so it does not extend `Throwable`, and a bug goes
to ZIO's defect channel instead. The member carrying the server's own text is
`logMessage`, whose name states that it goes to the log and never to a client
(ADR-035 §3). The match is exhaustive over the sealed hierarchy, so a new leaf
type that no arm handles is a compile error rather than a runtime surprise.

### ❌ Imperative Predicate Checks

```scala
// BAD: Manual if/else with ad-hoc failure
TreeIndex.fromNodeSeq(nodes).flatMap { index =>
  if !index.nodes.contains(rootId) then
    Validation.fail(ValidationError(ErrorLocation.requestField(FieldName.RootId), FieldProblem.RootIdNotFound(rootId)))
  else Validation.succeed(RiskTree(id, name, nodes, rootId, index))
}

// GOOD: Declarative predicate with fromPredicateWith
TreeIndex.fromNodeSeq(nodes).flatMap { index =>
  Validation
    .fromPredicateWith[ValidationError, TreeIndex](
      ValidationError(ErrorLocation.requestField(FieldName.RootId), FieldProblem.RootIdNotFound(rootId))
    )(index)(_.nodes.contains(rootId))
    .as(RiskTree(id, name, nodes, rootId, index))
}
```

### ❌ Logging at HTTP Boundary

```scala
// BAD: Log in pure encoder
def encode(error: Throwable) = {
  logger.error(s"Error: $error")  // Side effect in pure function!
  (StatusCode.InternalServerError, ...)
}

// GOOD: Log at service layer before boundary
def serviceMethod = 
  businessLogic.tapErrorCause(cause => ZIO.logErrorCause("Failed", cause))
```
